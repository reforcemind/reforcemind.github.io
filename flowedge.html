FlowEdge

Low-latency inference for real-time robotics policies

A C++23 inference runtime for low-latency robotics policies. The current mainline supports Mamba + flow-matching inference and a fixed-shape LeRobot Diffusion Policy deployment path.

Static Runtime Memory

Zero heap allocations after engine initialization. Predictable, fast, and rock-solid for mission-critical robotics.

Native Safetensors

Seamless loading and checkpoint conversion directly within the C++ runtime. No Python overhead required.

Deadline-Aware Inference

Optional Relay layer ensures your policies execute exactly when needed, maintaining strict real-time control loops.

Absolute reproducibility with deterministic state snapshot and restore capabilities built right in.

Performance Highlights

We don't publish generated-checkpoint or fixed-token speedups as policy-latency evidence. Our focus is squarely on captured visual-policy replay, direct PyTorch comparisons, and actual end-to-end latency in real-world scenarios.

Ready to deploy?

terminal C++ Integration

Requires CMake 3.21+ and a C++23 compiler.

Build & Run

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j

wget -qO models/mamba_flow.safetensors \
  https://huggingface.co/...

./build/flow_sample models/mamba_flow.safetensors euler 10

code Python Package

Uses the exact same high-performance C++ engine.

Install & Sample

python -m pip install .
python examples/core/flow_sample.py models/mamba_flow.safetensors

Use Engine.sample(prefix, noise, steps, method) with euler, heun, or rk4.
